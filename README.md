# TARANG69 - เว็บตารางเรียนอัจฉริยะ ม.6/9 📅

เว็บแอปพลิเคชัน (PWA) ตารางเรียน ม.6/9 แผนการเรียนวิทย์-คณิต รองรับการแสดงผลทั้งบนโทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์

## ฟีเจอร์หลัก (Features)
- ⏱️ **Timeline Progress Tracker:** แสดงคาบเรียนปัจจุบันและคาบถัดไปแบบเรียลไทม์ พร้อมเปอร์เซ็นต์ความคืบหน้าของแต่ละคาบ
- 🏫 **ข้อมูลห้องเรียน & คุณครู:** ระบุห้องเรียนพิเศษชัดเจน (เช่น Lab 327, Lab 325, ห้องคอม 6) พร้อมชื่อครูผู้สอน
- 📱 **Mobile-First & PWA Support:** ใช้งานได้รวดเร็ว ลื่นไหล พร้อมติดตั้งลงหน้าจอมือถือ (Add to Home Screen) รองรับ Offline Cache ผ่าน Service Worker
- 📊 **สลับมุมมองได้:** ดูแบบการ์ดรายวัน (Daily Cards) หรือตารางเรียนรวมทั้งสัปดาห์ (Weekly Table View)
- 🖨️ **Print Friendly:** รองรับการสั่งพิมพ์ตารางเรียนออกเป็นกระดาษ A4 แนวนอนได้อย่างสมบูรณ์

## Tech Stack
- HTML5, CSS3, JavaScript (Vanilla ES6+)
- Tailwind CSS
- Service Worker & Web App Manifest (PWA)
